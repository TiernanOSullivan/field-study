# Field Study — Water Temperature Analysis

The project calculates the arithmetic average of the measured water temperatures in celcius.

## Research question

What is the average water temperatures measured in the field study

## Repository contents

- `calculate_mean.py` — calculates the mean
- `methods.md` — information on the utilized approach
- `raw-data/` — recorded data

## Requirements

- Python 3 (no additional libraries are needed)
- No further action was needed. 

##Expected results
- Average mean: 18.25C

## Run the analysis
python calculate_mean.py
From the repository directory:

```bash
python calculate_mean.py
```

Expected output after the correction:

```text
Mean water temperature: 18.25 C
```
